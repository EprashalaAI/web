## 3. Core Syntax Rules

### A. The Memory Suffix (`-मध्ये`)
Panini tracks variable memory destinations using the suffix **`-मध्ये`** ("In / Into"). Whenever you store data, perform mathematical operations, or prompt for user input, the target variable **must** end with `-मध्ये`.

* **Valid Targets:** `क-मध्ये`, `total-मध्ये`, `age-मध्ये`

### B. Flexible Word Order
Because the `-मध्ये` suffix explicitly identifies the destination variable, standard single-line commands are order-independent:

```sanskrit
५ क-मध्ये स्थापय       // Value -> Destination -> Action
स्थापय ५ क-मध्ये       // Action -> Value -> Destination
क-मध्ये ५ स्थापय       // Destination -> Value -> Action

## Introduction

Welcome to **Panini**, an educational programming language engineered to replace Turbo C and C++ in schools. Named after the ancient Sanskrit grammarian, Panini uses a **Kāraka (Suffix-Based) Engine**.

Unlike modern languages (like Python or C) that strictly enforce *word order*, Panini understands the *role* of a word based on its suffix. This allows students to focus entirely on computational logic rather than fighting syntax errors, missing semicolons, or rigid boilerplate.

## 2. Core Syntax Rules

### The Memory Suffix (`-मध्ये`)

The most important rule in Panini is the `-मध्ये` (In / Into) suffix. Whenever you want to save data into a variable (whether you are storing a number, doing math, or asking for input), the target variable **must** end with `-मध्ये`.

* **Valid Destination:** `क-मध्ये` (Into variable 'ka')
* **Valid Destination:** `sum-मध्ये` (Into variable 'sum')

### Comments

Use double slashes `//` to write notes. The compiler ignores everything after `//` on that line.

```sanskrit
// This is a comment. It explains the code below.

```

### Word Order Flexibility

Because of the `-मध्ये` suffix, single-line commands can be written in any order! These three lines are mathematically identical to the compiler:

```sanskrit
५ क-मध्ये स्थापय       // Value -> Destination -> Action
स्थापय ५ क-मध्ये       // Action -> Value -> Destination
क-मध्ये ५ स्थापय       // Destination -> Value -> Action

```

## 3. Input and Output (I/O)

### Print / Output (`वद`)

Use **वद** (Speak) to print text, numbers, or variables to the terminal screen. You can string multiple items together by separating them with spaces.

* **Strings** must be enclosed in double quotes `"..."`.

```sanskrit
वद "Hello World"
वद १००
वद "The answer is " उत्तर

```

### User Input (`पृच्छ`)

Use **पृच्छ** (Ask) to prompt the user for input. It automatically detects whether the user typed a Number (Integer/Float) or a Text String, and saves it. The destination variable must have the `-मध्ये` suffix.

```sanskrit
पृच्छ नाम-मध्ये        // Pops up asking for 'नाम' (Stores string)
पृच्छ आयु-मध्ये        // Pops up asking for 'आयु' (Stores number)
वद "Hello " नाम " your age is " आयु

```

## 4. Variables & Memory Assignment

### Store / Assign (`स्थापय`)

Use **स्थापय** (Store) to initialize or overwrite a variable. Requires a value and a destination.

```sanskrit
१० क-मध्ये स्थापय      // Sets ka = 10
"Rahul" नाम-मध्ये स्थापय // Sets naam = "Rahul"

```

## 5. Mathematics & Data Manipulation

All mathematical operations require **three parts**: Value 1, Value 2, and a Destination.

### Addition / Concatenation (`संयोजय`)

If used on numbers, it adds them. If used on Strings, it joins them together.

```sanskrit
५ १० संयोजय योग-मध्ये     // योग = 5 + 10
वद योग                   // Prints: 15

"Bat" "man" संयोजय नायक-मध्ये
वद नायक                  // Prints: Batman

```

### Subtraction (`न्यूनय`)

```sanskrit
२० ५ न्यूनय उत्तर-मध्ये     // उत्तर = 20 - 5

```

### Multiplication (`गुणय`)

```sanskrit
५ ४ गुणय उत्तर-मध्ये      // उत्तर = 5 * 4

```

### Division (`विभज`)

```sanskrit
१०० ५ विभज उत्तर-मध्ये    // उत्तर = 100 / 5

```

## 6. Control Flow & Logic (CFG Blocks)

While standard statements are free-order, structural logic (Loops and Ifs) use standard Context-Free Grammar (CFG) block structures with `{ }` brackets.

**Supported Operators:** `==` (Equal), `!=` (Not Equal), `>` (Greater Than), `<` (Less Than).

### If / Else (`यदि` / `तर्हि`)

Requires the condition in parentheses `( )`, and the code block in braces `{ }`.

```sanskrit
पृच्छ आयु-मध्ये

यदि ( आयु > १७ ) {
    वद "You are an adult."
} तर्हि {
    वद "You are a minor."
}

```

### While Loops (`यावत्`)

Executes the code block repeatedly as long as the condition remains true. (The Panini engine has a built-in infinite-loop safeguard set at 2000 iterations to protect school computers from crashing).

```sanskrit
५ चक्र-मध्ये स्थापय

यावत् ( चक्र > ० ) {
    वद "Countdown: " चक्र
    चक्र १ न्यूनय चक्र-मध्ये   // Subtract 1 from Chakra
}
वद "Blastoff!"

```
